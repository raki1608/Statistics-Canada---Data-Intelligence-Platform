\# Statistics Canada - Data Intelligence Platform



An end-to-end data engineering project that transforms Canadian public datasets from StatCan into analytics-ready data for reporting and analysis.



\## Objectives



\- Ingest public datasets using Python.

\- Process and transform data using PySpark.

\- Store structured datasets in Parquet format.

\- Build an analytics layer using DuckDB and SQL.

\- Implement data quality checks and automated tests.

\- Develop a Power BI dashboard for data exploration.

\- Introduce version control and automated validation with GitHub Actions.



\## TechStack Used



\- \*\*Language:\*\* Python

\- \*\*Data Processing:\*\* PySpark

\- \*\*File Format:\*\* Parquet

\- \*\*SQL Engine:\*\* DuckDB

\- \*\*Data Analysis:\*\* Pandas

\- \*\*Testing:\*\* Pytest

\- \*\*Code Quality:\*\* Ruff

\- \*\*Visualization:\*\* Power BI Desktop

\- \*\*Version Control:\*\* Git



\## PrimarySources



The project will use publicly available Canadian datasets, starting with Statistics Canada.



\## Architecture



The pipeline will follow a layered architecture:



1\. \*\*Raw:\*\* Original downloaded datasets.

2\. \*\*Processed:\*\* Cleaned and transformed datasets.

3\. \*\*Gold:\*\* Analytics-ready datasets for SQL queries and reporting.
